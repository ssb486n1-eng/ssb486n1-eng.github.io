원문

⚙️ 설정

API 없이 동작하는 원리
음성 인식·번역·음성 합성을 브라우저 내장 엔진 또는 기기에서 직접 실행하는 오픈 모델로 처리합니다. 서버·API 키·사용료가 없고, 모델을 한 번 받아 두면 오프라인에서도 동작합니다. 자동 설정은 PC·태블릿·폰의 성능을 측정해 모델 크기를 고릅니다.

언어

자동: 통역 음성이 상대에게 전달되면 상대 차례로 보고 상대 언어로 듣습니다. 인식 결과가 듣던 언어와 다른 문자(예: 한국어로 듣는데 영어)로 나오면 상대 발화로 바로잡습니다. Whisper 엔진은 음성으로 언어를 직접 판별합니다. 예측이 틀리면 화자 버튼을 눌러 바로잡을 수 있습니다.

음성 인식

자동: 기기 내 Web Speech → (완전 로컬 모드가 아니면) 브라우저 기본 Web Speech → Whisper
안드로이드 Chrome 의 연속 인식은 같은 문장을 반복해서 보내는 경우가 있어, 문장 단위로 인식하고 중복을 걸러냅니다.
말하는 동안은 작은 모델로 빠르게 초안을 내고, 발화가 끝나면 큰 모델로 한 번 더 인식해 확정합니다. 확정문이 초안과 크게 다르면 번역을 다시 해서 화면을 ✎ 정정합니다.
용어 프롬프트 (인식 정확도)용어집과 직전 발화를 Whisper 에 문맥으로 주고, Web Speech 에는 문구 가중치(contextual biasing)로 전달합니다. 프롬프트를 그대로 베낀 결과는 자동으로 버리고 다시 인식합니다.

번역

방향 전용 모델(Opus-MT)은 해당 언어쌍이 있을 때만 쓰고, 없으면 다국어 모델로 자동 전환합니다. Chrome 내장 번역이 직접 지원하지 않는 쌍은 영어를 거쳐 번역합니다.

동시통역 전략

2 = 연속 2개 인식 결과가 일치하면 확정 (빠름) · 3 = 3개 일치 (안정)
미완성 구간 미리보기확정 전 구간을 반복 재번역해 흐리게 표시 (번역이 빠를 때만 자동 동작)
5초 넘게 이어지는 발화는 짧은 쉼(0.28초)에서도 끊어 지연을 줄입니다.

음성 출력

내 말 통역 낭독상대에게 들려줄 음성
상대 말 통역 낭독이어폰으로 들으면 편합니다
밀리면 자동 가속낭독 대기열이 쌓이면 최대 1.7배까지 빨라집니다

용어집

전문용어 강제 적용번역 전에 원문 용어를 표준 대역으로 치환 → 번역 결과 용어 일관성 확보 (기본 용어 개). 인식 결과의 약어(알씨에스→RCS)·띄어쓰기(냉각 탑→냉각탑)도 교정합니다.

보안·기록

완전 로컬 모드음성·텍스트가 기기 밖으로 나가는 엔진(클라우드 Web Speech, 네트워크 음성)을 사용하지 않습니다
기록을 이 기기에 저장끄면 화면을 닫는 즉시 사라집니다
