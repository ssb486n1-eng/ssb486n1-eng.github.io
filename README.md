# 로컬 동시통역 (No API)

API 키·서버 없이 브라우저 안에서 음성 인식·번역·음성 합성을 처리하는 실시간 통역 웹앱의 **배포본**입니다.

- 접속: https://ssb486n1-eng.github.io/
- 통역 음성·텍스트는 기기 밖으로 전송되지 않습니다 (모델 파일 다운로드만 Hugging Face 에서 수행).
- `vendor/` 는 npm 레지스트리의 `@huggingface/transformers@3.7.6` 에서 sha512 무결성을 검증한 뒤 복사한 런타임입니다.

이 저장소는 빌드된 파일만 담고 있습니다. 직접 수정하지 마세요.
